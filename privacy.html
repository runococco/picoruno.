プライバシーポリシー

picoruno.（以下「本サイト」）で、どんな情報をどのように扱っているかをまとめたページです。本サイトには会員登録やログインはなく、お名前・メールアドレス・住所などの個人情報をお預かりすることはありません。

1. ブラウザに保存する情報

ゲームを快適に遊んでいただくため、お使いのブラウザの中（localStorage・sessionStorage）に次の情報を保存します。これらは端末の中だけに残り、運営者が見ることはできません。

  • ハイスコア、遊んだ回数、音量などの設定
  • 「いいね」を押したゲームの記録
  • 「誰かのメモ帳」で自分が書いたメモの記録
  • 同じゲームの遊んだ回数が二重に数えられないようにするための目印

ブラウザの設定から「サイトデータの削除」を行うと、いつでも消すことができます（ハイスコアなども消えます）。なお、本サイト自身はCookieを使用していません（下の外部サービスが、それぞれ独自にCookieを使う場合があります）。

2. サーバーに送る情報

次の情報を、データベースサービス Supabase に送信して保存します。いずれも、どなたのものかはわからない形で扱います。

  • 遊ばれた回数・いいねの数：ゲームごとの合計数だけを記録します。誰が遊んだかは記録しません。
  • 「誰かのメモ帳」に書いたメモ：書いた文章（40文字まで）と投稿日時を保存し、ほかの方に表示します。名前やアカウントはありません。個人が特定できる内容は書かないでください。
  • 連投・通報の判定用の値：「誰かのメモ帳」では、荒らし対策のため、接続元のIPアドレスを日付と組み合わせて変換した値（日ごとに変わり、元のIPアドレスには戻せません）だけを保存します。IPアドレスそのものは保存しません。

3. 外部サービスの利用

本サイトでは、次の外部サービスを利用しています。ページを開いたときに、お使いの端末からこれらのサービスへ通信が発生し、IPアドレスやブラウザの種類などの技術的な情報が各社に送られることがあります。送られた情報は、各社のプライバシーポリシーに従って扱われます。

サービス使っているところ・目的
GitHub Pagesサイト全体の公開（ホスティング）
Google Fonts文字のフォントの表示
Supabase遊ばれた回数・いいね・「誰かのメモ帳」のデータ保存
cdnjs（Cloudflare）一部のゲームで使う3D表示用のプログラムの読み込み
OFUSE「つくった人」ページの応援ボタン
X（旧Twitter）結果をシェアするボタン（押したときだけ通信します）

現在、本サイトでは広告やアクセス解析ツール（Google アナリティクスなど）は使用していません。今後導入する場合は、このページを更新してお知らせします。

4. 情報の利用目的

集めた情報は、ゲームの記録の保存、人気のゲームの表示、「誰かのメモ帳」の運営と荒らし対策、サイトの改善のためにだけ使います。法令にもとづく場合を除き、第三者に提供することはありません。

5. 「誰かのメモ帳」の投稿について

不適切な投稿は、通報の数などにもとづき、予告なく非表示または削除することがあります。ご自身が書いたメモを消したい場合は、下の連絡先までご連絡ください。

7. ポリシーの変更

必要に応じて本ポリシーを変更することがあります。変更後の内容は、このページに掲載した時点から効力を持ちます。
